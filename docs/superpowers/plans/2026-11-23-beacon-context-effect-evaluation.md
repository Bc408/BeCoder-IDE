**目标：** 取得可追溯的实际模型取材、事实判断、教学和故障恢复证据，交付干净staged应用及详尽能力报告。

**边界：** 保持软件采集资格与模型消费权限分离；讨论对象由LLM判断，不恢复绑定；只上传合成材料；不改学生源码、不自主执行／交题；不提交、推送、Setup或发布。保留当前dirty tree与用户便携数据，最后构建不混入个人或测试数据。

## 评判与停止条件

机制边界必须全部通过；伪造读／存／运行／判词及跨根／会话泄露阻断交付。语义门槛为自然取材≥95%、回答评分≥4/5的比例≥90%，各组分别报告。未达标则报告真实结果和瓶颈，不以总体平均掩盖。模型自评是辅助证据，主代理与独立审阅核查判据及失败样本。测试用例描述、工具输出与摘要均保持材料身份。

## 验证预检
