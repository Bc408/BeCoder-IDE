## 已实现的范围

- 公开 ACM 标准输入输出题与已结束、公开、个人可提交的比赛题，完整 C／C++ 程序。公开 `18204.cpp` 与比赛 `5657_A.cpp` 保留不同入口，按可配置牛客目录猜题；目录外纯数字不抢占站点。
- 复用共同源码快照、语言选择、题面、导入及结果控制器。左侧牛客登录／退出使用当前持久浏览器 Session；普通读取、提交和查结果不创建网页或隐藏窗口。
- 原生固定 `/nccommon/submit_cd` 单次发送、`/nccommon/status` 只读查询。正式 ID 到达即释放发送资源；未知受理不重投，无备用接口、队列或预热。
- 题面使用既有 HTML 清洗、公式图片、高亮与复制控件，保留样例说明；结果复用洛谷布局与蓝色等待动画。三站限制值沿用洛谷简洁格式，牛客按标签匹配并仅保留 C/C++ 数值。缺失分数、官网代码长度省略，真实通过数量单列汇总，不制造逐点结果。
- 记录页保留同一响应或本次准备时已取得的题名，洛谷题号使用官方难度颜色。牛客保留已发送的语言、账号及本地源码快照；明确标为“本次提交源码”，不称为官网回读。未增加取数请求。
- 三站每轮本地跟踪约120秒，到期保留记录与最后状态，允许继续查询；洛谷推送、AtCoder 官网 Interval 和牛客2秒间隔保持各自语义。编译器偏好按站点及 C／C++ 分键。

Acorn 8.16.0 是明确批准的生产依赖，随 root lock、MIT 原文、第三方声明和组件清单登记。解析器位于 `electron-main/nowcoderProtocol.ts`，按需加载 Acorn，只读取官网 JS 字面量，不执行远程代码。身份校验位于不依赖 Acorn 的 `common/nowcoderBridge.ts`，未增加另一套通用请求框架。
