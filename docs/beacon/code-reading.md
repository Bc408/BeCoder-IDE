# Beacon 实时代码读取

修订：2026-11-24。按负责人逐项审阅明确可见页面和整稿范围，codesnap全部撤回。旧合同从Git备份74d09ef4追溯，当前见[工具设计0.4](../superpowers/specs/2026-11-23-beacon-tool-interface-simplification-design.md)。

## 1. 调用语义

readCurrentCode({})一次返回调用当下所有可见分屏中的C/C++代码页面。可见用于选择页面，正文范围是每页整份代码，含屏幕外行与未保存修改；不读后台标签，不只读焦点页或屏幕可视行。

未命名可见C/C++页面同样读取，filePath:null，不要求先保存。实际接口为files数组及fileName／filePath／isDirty／code；读取错误不能冒充无页面。模型无需先列代码页或复制pageId／version；当前焦点只是观测，不固定讨论对象。没有可读页面时如实表示，不回退上轮文件或磁盘版本。

新的调用取得修改后的代码；发送、继续、重答不自动读取，重放不执行。工具不打开或切换页面。

## 2. 没有独立代码存储

无代码正文库、队列、目录、历史回读、保存状态、去重、晋升、容量或淘汰，也无跨调用全文缓存。旧256KiB快照上限已失效，run的8KiB只限制编译／程序输出，不裁源码。

代码真实返回沿普通对话处理。run执行稿和verdict实际提交稿属于原记录，不另入代码存储；历史稿不冒充当前稿。

完整结果加入后超过模型上下文，沿既定同步压缩和一次有界恢复处理，仍装不下诚实失败；不为新代码工具增加分页或依剩余容量二次裁剪。模型不因预算改读另一页。

## 3. 模式与隔离

三档按原页面权限读当前可见代码，所有模式均不额外保存副本；不授backing file、邻近文件、其他会话或敏感路径权限。

旧返回按有效历史处理，没有整段对话代码队列例外。旧磁盘快照原文件保留隔离，不自动迁移或删除。

## 4. 提示与验收

description只表达读取用途，内部ID默认不转述、不搬运整稿等放system，不混入保存逻辑。

后续验证多可见分屏、后台标签排除、整稿／dirty、新改稿、敏感过滤、完整输入预算和零额外代码落盘。候选源码已接入多可见分屏整读、零快照存储，并有分项回归；最终验证与桌面验收见[实现状态](implementation-status.md)。
