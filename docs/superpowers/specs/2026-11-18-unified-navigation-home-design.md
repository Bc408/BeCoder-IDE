# BeCoder 统一导航首页设计

日期：2026-11-18。基线：`OJ_connect` / `573b0e96`。负责人已逐项确认交互，并明确授权收敛文档、自行推进实现；本文是本轮实现依据，完成情况另记验证记录，不将设计当作验收。

## 目的与边界

将“开始”和内置浏览器空白页统一成一个本地导航首页，减少进入竞赛网站、搜索与创建学习文件的步骤。首页归原生 browserView 所有；OJ Connect 继续拥有题目关联、导入、提交、评测及账号业务；CPH、NoteBook 仍各自拥有文件和样例流程。不修改网站协议、登录会话、隔离策略或提交链路，不新增依赖、远程首页、前端框架、历史数据库或管理弹窗。

## 已确认的交互

| 入口 | 行为 |
| --- | --- |
| 应用标题栏唯一主页按钮 | 聚焦已有首页；没有则新建。不得覆盖网页、源码或强行搬动标签 |
| 编辑器标签栏＋ | 每次新建首页标签 |
| 浏览器导航栏主页 | 当前浏览器标签返回首页，可后退到先前网页 |
| 启动时原本应显示欢迎页 | 显示同一首页；保留 startupEditor、恢复编辑器、skipWelcome 和焦点规则 |

首页包含搜索、用户配置的网站链接、新建 C、新建 C++、新建 BeCoder NoteBook。没有最近文件区域。网站链接与搜索在当前标签打开；新文件进入正常编辑器组，避免落入浏览器锁定组。首页是 browserView 内容区的本地 DOM；空 URL / `about:blank` 统一代表首页，不引入新的网站路由。浏览器返回、前进、恢复、隐藏原生视图时须核对实际表现。

首页品牌横向排列 BeCoder 图标和名称，下方小字“一切就绪”；网站链接在宽屏每行最多七个，窄屏自然换行且保留全部配置。地址栏与标签悬停不暴露内部空白 URL。允许关闭最后一个首页与全部编辑器，保持空编辑区，只有显式点击主页／＋或既有启动规则才创建首页。主页复用排除正在导航到网站的标签；返回首页仅在当前浏览器容器持有焦点时聚焦搜索框。

## 搜索与设置

地址栏和首页使用同一 `browserSearch.ts` 的分类、编码、搜索 URL 构造和默认引擎配置。保留 Bing、Google、Yahoo、DuckDuckGo 和禁用选项；增加按名称与含 `{query}` 的 HTTP(S) URL 模板配置的自定义引擎。无效配置安全忽略，不执行配置中的脚本。通过既有“浏览器设置”进入原生设置页，无单独管理器。

网站链接继续使用 `becoder.welcome.onlineJudgeSites`（名称到 URL）与 `becoder.welcome.onlineJudges`（有序名称列表），直接复用既有校验函数；不迁移、不复制、不丢弃用户配置。在原生浏览器设置入口同时显示相关配置。列表为空则不显示空站点卡片。

## 文件与历史

C/C++ 创建指定语言的未命名文档，复用原生保存对话框的语言后缀推断，默认分别为 `.c`、`.cpp`，不叠加后缀、不改写用户明确输入的文件类型。NoteBook 调用现有 `becoder.notebook.new`，保持其文件夹选择及 `.bcnb` 保存流程。

浏览器工具栏右侧提供历史入口，扩展现有 QuickPick，分“最近文件”“网页历史”两组。最近文件复用原生最近文件服务和既有顺序，不限当前文件夹；网页历史沿用当前浏览器会话的时间排序与存储隔离。两组共用搜索。文件在正常编辑器打开、网页在当前浏览器标签打开；地址栏建议仍仅使用网页历史。删除文件历史走最近文件服务；清除浏览器数据不清除文件历史。两组不伪造统一时间戳，不另建持久层。

## 源码落点与去冗余

- `browserWelcomeFeature.ts`：唯一首页内容、设置变化更新、搜索及文件入口。
- `browserSearch.ts`、`browserSearchFeatures.ts`、`browserNavigationFeatures.ts`：统一引擎扩展与设置入口。
- `browserTabManagementFeatures.ts`：主页复用／新建命令、导航栏主页和标题栏入口。
- `browserHistoryFeature.ts`：现有历史选择器内补充文件记录、右侧工具栏入口。
- `startupPage.ts`、`gettingStarted.contribution.ts`：正常欢迎启动与旧欢迎命令转向统一首页；保留显式 walkthrough 所需组件。
- `beCoderNewTab.contribution.ts`：移除第二个自动启动所有者；旧新建命令转发到原生新标签；旧序列化资源可恢复到新首页，不保留第二套可见首页。
- `multiEditorTabsControl.ts`：复用既有标签结构，添加＋入口，不打破 tabCount、滚动和拖动假设。

只按真实引用清理旧页实现。保留通用浏览器命令，携带 URL 的登录／OJ 调用仍直接打开指定页面。启动只能有一个权威路径，不能因新首页额外覆盖恢复结果。
