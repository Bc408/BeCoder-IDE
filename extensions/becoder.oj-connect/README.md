# OJ Connect

BeCoder 内置刷题扩展，当前源码接入洛谷与 AtCoder。需要包含对应浏览器宿主的 BeCoder 构建。

聚焦 C/C++ 源码，**Ctrl+Alt+P** 查看题面，**Ctrl+Alt+S** 提交当前编辑稿（含未保存内容），正式 ID 确认后打开共同评测页。题面可选择站点语言，快捷键沿用同一选择；尚未取得可用语言时在提交时选择。洛谷使用内置浏览器同一持久会话直接请求，常规操作无需保留网页；验证码按上游图片面板输入，留空刷新。AtCoder 保留原网页验证及草稿替换确认流程。

在内置浏览器题页点击 Import，将 `.cpp` 放在工作区直接子目录并打开共同题面；已有源码与未保存稿保留。题面上另点“导入 CPH”才把样例关联到这份源码。缺失限制会在 CPH 明示使用本地默认限制，不伪造网站数据。

`becoder.ojConnect.directories` 默认 `luogu`、`codeforces`、`atcoder`、`lanqiao`、`nowcoder`，设置修改不会移动已有文件。直接父目录优先，再猜文件名；失配提示输入，不建持久绑定库。例：`luogu/P1001.cpp`、`atcoder/abc086_a.cpp`；显式上下文例 `P1001@123.cpp`、`tenka1-2019-beginner@tenka1_2019_a.cpp`。无目录的 `AT_abc086_a.cpp` 有歧义时提示，不静默选站。

独立 OJ Connect 活动栏入口提供五站登录摘要和已接入站点的登录／退出操作，与内置浏览器共用登录。CF、牛客、蓝桥显示“尚未接入”。没有题库、比赛、社交或专栏入口。

每窗口一项提交；洛谷明确验证码拒绝后人工输入可继续，同一次提交中已输入答案连续被拒绝三次即停止，并在右下角提示“请到内置浏览器中提交，并手动完成认证。”首次挑战、留空刷新和取消不计入次数，不实现新的认证形式。受理不明只查询，不能自动重交。记录页自动更新，读取失败时才显示继续查询；关闭记录停止只读跟踪。停止不会撤回已受理的提交；扩展重启不持久恢复任务、语言偏好或最近记录。

题面与评测前端按 vscode-luogu 4.20.0 对齐，直接复用其核心 React 组件、CSS 与宿主 Markdown 渲染链，移除题解、比赛及其他外围能力；原组件及必要适配对照见 UPSTREAM.md。

开发命令：`npm run typecheck`、`npm run build`、`npm test`、`npm run test-render`。构建包含站点脚本、Webview JS/CSS、KaTeX 字体；运行时无外部 npm 依赖。许可与来源见 UPSTREAM.md、ThirdPartyNotices.txt。设计、当前检查和真实验收分别见 [开发入口](../../docs/oj-connect/README.md)。本次两站共同界面仍需负责人在新构建验收。
