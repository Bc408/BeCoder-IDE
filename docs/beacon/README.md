## 不重新开题的核心边界

- Beacon 工作区按窗口独立选择和记住；最近列表共享，同工作区共享历史与独立记忆。模式资格由工作区有效性决定：无可用根仅 blackout，有有效根仅 spot/flood；记住但失效的根保留选择并提示，暂仅 blackout。
- 忙时拒绝本窗口切换，空闲切换进目标历史列表。对话及附件、快照、归档状态固定归属，临时对话不自动转存或带入新会话。同一对话只能在一个窗口打开，其他窗口仅提示，无切换入口。
- `.beaconWork` 与 `.notebook` 独立，允许不同根。Notebook 的源码关联按编辑器打开根、相对路径和完整源码文件名匹配，内容独立；不跟随源码改名、移动或删除。
- 用户选择工作区时由 BeCoder 建立并确保合法可用的 `.beaconWork` 资产目录，随后随该窗口工作区内 Runner/CPH/Notebook 用户运行行为落盘对 Beacon 有帮助的完整证据，不等到模型请求才开始采集。Runner/CPH 两条约 10 次 FIFO 独立；Notebook 行为证据独立、不挤队列，每份 input 仍仅保留最近结果；根外行为不写入该区。
- 三档均允许按需读取本窗口用户当前打开的编辑器页面内容，包含未保存修改、已打开的本人 OJ 提交代码/判题详情；页面可能含个人信息，默认用户已知情可被 Beacon 阅读，不额外询问。页面读取不授予对应磁盘文件、目录、引用文件或隐藏记录的读取权；凭据过滤和会话隔离仍有效。blackout 不自由读取工作区行为记录或持久化记忆、不落盘会话。
- 只要进一步通过网络查询个人信息，不限算法竞赛/OJ 场景，都须问询并取得用户明确许可；已有明确许可且范围匹配时可以复用。用户许可和限制可由主模型记入 teach tips，授权依据由受控宿主核验，模型自写记忆不能产生新许可。许可不授权登录、提交或扩大档位的文件范围。
- 外部单文件主动添加不授权目录或持续追读。有限写入只面向自身资产和明确请求的学习资产，不改学生 C/C++ 源文件，不自主执行或交题。
- 记忆仅工作区级：主模型维护 tips，status 日常追加，用户可直接编辑；dream 主动整合并保存旧 status 的可读归档。删除来源对话不删除派生记忆或独立学习资产。
- Notebook 四条完整流程、洛谷/Codeforces/AtCoder/蓝桥云课题库内置网页优先流程、主模型简单追加 tips 已明确首版，不擅自缩水或延期。

上述摘要用于导航，完整规则以各归属章节为准。人格细化、整体剩余版本范围及少量产品取舍仍见 PRD，不用技术候选方案替负责人作产品决定。
