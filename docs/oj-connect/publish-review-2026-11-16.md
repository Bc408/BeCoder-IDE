# OJ Connect 分支发布前审查（2026-11-16）

本轮范围为 `OJ_connect` 的代码审查、去冗余、计划语义校对、许可补齐和提交检查准备。不提交、不推送，不构建新的 stage 或 Setup，也不发送真实 OJ 提交。

## 已修复的问题

- AtCoder 准备句柄的两分钟回收计时器曾在开始发送后继续运行，可能中断尚在等待人工验证或回执的事务。消耗准备句柄后停用该计时器，实际发送仍由原生事务管理自己的截止时间。回归覆盖准备 119 秒后发送、跨过旧回收时间的情形。
- 关闭评测页后，核心层仍保留包含完整源码的已完成快照。现在随页面释放该快照；保留重开所需的小型记录身份与会话范围，重新打开时读取新结果。洛谷和 AtCoder 均有回归。
- 大量未闭合公式触发重复后缀扫描。现在惰性计算有效闭合位置和后缀最大宽度，失败查找不再重复扫描；成功查找消费对应行区间。确定性扫描次数测试先失败后通过，另对照公式宽度、代码块及 CRLF。64KB 合成输入在本机从约 2416ms 降至 251ms；这不是正常题面或流式 p95 的性能承诺。

## 去冗余与职责复核

删除扩展中只有测试使用的洛谷协议解析器，将其 11 项有价值回归移到实际运行的核心解析器。对应旧编译产物已定点清除，扩展测试不再执行删除源码的残留测试。

保留共同操作流程、站点适配、原生会话／发送和共享内容渲染的既有边界。这些边界分别处理用户流程、站点差异、浏览器凭据及内容展示；本轮不增加通用浏览器引擎、提交队列、绑定数据库或新的认证方式。共享解析器补齐局部 AST 与管线类型，移除宽泛 `any`，没有为通过检查关闭规则。

## 文档与许可

当前入口区分已确认要求、当前源码、历史证据和候选验收。CF、牛客、蓝桥尚未实现；牛客／蓝桥调研涉及官网内部接口，不能描述为稳定开放 API 或既有支持。

OJ Connect 主许可证对齐 `GPL-3.0-or-later`；保留洛谷插件及共享 Markdown 来源的 MIT 全文与归属，补齐 Lucide 图形的 ISC 全文。构建生成的 OJ 运行时依赖清单中，126 个 name/version 均在通知中有记录；Beacon 构建也保留共享组件的完整通知。根许可索引同步维护。

发布文件清单未包含浏览器数据、数据库、日志、截图、安装包或测试归档，常见密钥签名扫描未命中。本地忽略目录保留审计证据；清理五个合成 Electron 配置目录的命令被自动审批策略拒绝，未改用其他方式删除。这些目录不进入 Git 发布。
