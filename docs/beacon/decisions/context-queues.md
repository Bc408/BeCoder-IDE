# Beacon 队列与取材决定

更新：2026-11-24。汇总负责人逐项问答，以最后修订覆盖中间选择。接口主文见[工具设计0.4](../../superpowers/specs/2026-11-23-beacon-tool-interface-simplification-design.md)，清洗前原件由Git备份74d09ef4追溯。

## 1. 三个持久队列

| 队列 | 已确认决定 |
| --- | --- |
| problem | 当前.beaconWork共享13条，五站Get／Import保存oj、problemId与真实查看时间；按problem（oj＋problemId）与filePath共同去重；同题同路径删除旧项、新ID及新viewedAt入队尾，不同路径分别占位，无题面正文 |
| run | 三来源共用30条，不去重；每份程序一次编译及其关联input运行一条，结束／失败／取消后入队，无运行中占位 |
| verdict | 20条，完整最终评测才入队；同站同题实际提交代码完全相同替换旧结果入尾，缺可靠代码照常保存并跳过去重 |

CPH单点／全部各占一个位置，全部包含多个测试点。Notebook同一代码块多个input是一条，涉及N个程序则分别记录；覆盖此前整个运行全部只一条的中间选择。代码编译失败保失败尝试，未执行input标明，未启动其他程序不伪造记录。

CPH“仅编译，不运行”不记录、不入run队列、不占位置，成功／失败／取消均如此；运行单测试点／全部测试点时的编译失败仍保留失败记录。CPH原有仅编译功能照常使用。

run目录与正文都不嵌入题目身份、标题、URL或题目候选，不透传CPH原始题目配置，关联由LLM判断。CPH仅保check结果，不保存检查器类型、配置、路径、代码、命令或诊断；检查器代码沉淀留后续事项，对拍检查器／随机生成器另作设计。

problem每次记录只表达本次行为对应文件；无可靠路径为null，同题同为null也按相同字段去重。旧ID不转指新记录，读取不改变查看时间。

## 2. 已定工具入口

readCurrentCode一次读取所有当前可见分屏C/C++页面的完整dirty正文、文件名和路径，后台标签不读；无独立代码保存／队列／目录／回读，无发送捕获。

readProblemRecord／readRunRecord／readVerdictRecord分别注册，空参按需列简短目录，带ID读完整持久记录，无独立目录工具或producer／revision／part／测试点矩阵。不额外分页，不因上下文不足再裁剪结果。

fetchProblem按oj＋problemId联网获取五站题面，与搜索开关互不影响，不改用户行为，无Get／Import／面板副作用或专门缓存。inspectFile、readPage、readMaterial、browseWeb保原能力；非五站可读.cph目录中的.prob元数据后普通联网兜底。editNotebook退出，写能力后续，独立Notebook保留。

## 3. run内容与Notebook执行

每条run保存一份程序／编译信息及多组输入结果，共同字段统一，特殊字段保来源差异，由harness整理。不保存本地运行限制配置；真实耗时、超时／输出超限等结束状态照常保留，原执行限制不变。Runner记录实际交给程序的输入与实际返回，不记录输入编辑按键。Notebook序号只数C/C++代码块，从1开始，属于执行时位置。

Notebook运行全部点击时固定本次代码与input，中途编辑下次生效；同代码块本次只编译一次，各input独立进程。编译失败继续其他块，input错误／TLE／OLE继续后续input，主动停止才结束批次。Notebook／Runner执行逻辑与采集适配器、存储解耦，采集不可用不控制执行或清理，无新增跨次编译缓存。

## 4. 输出上限与压缩

最后上限为每条run的编译输出及所有input实际程序输出合计8KiB＝8192 UTF-8字节，保头尾和真实省略量。该值覆盖中间256KiB选择，不是每个input额度，也不是整条记录或整个Notebook批量大小。

完整记录加入后超模型上下文，触发既定当前模型同步压缩，不二次裁剪、不增加分页。保持90%／60%、一步一次恢复与完整交换边界，仍装不下诚实失败。压缩不改持久记录，不重演工具。

## 5. verdict补充

最终判词已得但提交代码不可得时仍保存，跳过去重，不用当前代码补齐。只在同站同题范围比较可靠完整实际提交文本，空白／换行变化不归一化；不同题目／站点不互相替换。原站实际字段保留，不补隐藏测试。保存失败先保旧结果。

## 6. 模式、权限与状态

正常根才采集，Blackout有效根也持续采集；模式只裁Beacon持久目录／读取，无镜像、缓存旁路或跨档补采。LLM选对象，宿主无上轮对象、绑定库或强制流程；运行／测评不从功能页补读。
