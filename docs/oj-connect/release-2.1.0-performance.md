## 本轮实际优化与保留成本

favicon 连续2048个合法独特SVG在旧实现保留2048项、约884万URL字符；新生产监听器按上限32项淘汰，临时失败在下一事件重新获取，旧页面/旧事件/关闭后的响应不写回。此收益是确定的保留条目上限与正确性，不等同RSS/OOM或页面加载加速测量。关闭期间迟到 native 模型也会销毁，不再重新登记后台input；失败的创建Promise可重试。

未修改 AtCoder/CF 获取架构，保留固定 GET、15秒网络/10秒解析、8MiB边界、每次短命离线sandbox、原Session/取消和无缓存/预热/页面池/队列。没有证据支持为本轮加第二套性能机制；CF同题重开仍有重新GET成本。主页真实启动/DPI、长会话RSS及登录后端到端时间留在负责人候选验收，不填虚构数字。

本轮性能采证专用匿名 profile 与测试缓存位于审计目录，均不在新 stage/Setup 载荷；可选递归清理在执行前被自动审批策略拒绝，因此保留原状。测量日志、数值与截图也保留；没有把清理失败说成产物污染。
