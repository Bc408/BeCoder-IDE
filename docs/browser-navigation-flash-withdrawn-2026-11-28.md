## 原始现象与调查结论

深色内置浏览器在部分页面导航时短暂显示白底，随后恢复深色。负责人提供的复现路径是 Codeforces 首页点击登录；隔离本地 HTTP 服务的跨站导航与重定向也能复现，普通原生窗口及离屏帧记录均观察到白帧。

| 路线 | 已观察到的结果 | 归档结论 |
| --- | --- | --- |
| 默认背景色、导航回调重设深色 | 未消除过渡帧 | 不采用 |
| 原生覆盖控件、隐藏网页及截图／焦点补偿 | 覆盖控件未实际遮住网页；隐藏方案引入可见性、缓存与焦点生命周期 | 实验改动已撤回 |
| Chromium 静态深色启动参数 | 深色跳转改善，但浅色导航会重新变暗 | 不符合现有主题切换契约，不采用 |
| 官方 Electron 45.5.0／Chromium 156.0.8078.109 | 截图触发的深色覆盖回归通过，浏览器测试 39 项通过；真实导航及本地原生窗口仍有白帧 | 不接入项目，不以组件测试代替原问题验收 |
| 每网页持久原生深色偏好、自编 Electron | 仅完成源码接点与成本评估，没有实现或构建 | 因维护成本由负责人撤回 |

Chromium 官方提交 `a3d0cf0292e7c07979ce89a70cdac40bde093765` 修复了原生偏好刷新覆盖深色模拟的问题，但隔离实测证明它不足以消除本次导航白闪。另一个源码链路是导航切换旧渲染宿主时，旧调试会话拆除会撤销深色覆盖，新会话随后恢复；帧记录与该时序一致，未通过自编内核验证完整修复。
