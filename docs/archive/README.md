# BeCoder Archive Index

Checkpoint archive documents record what was true at an accepted historical checkpoint. The detailed development record is a historical snapshot that also preserves superseded plans. Both are evidence, not current product requirements.

When archive text conflicts with current documentation, authority is:

1. the project owner's latest explicit decision
2. `BECODER_PHILOSOPHY.md`
3. `BECODER_CURRENT.md`
4. the relevant document under `docs/contracts/`
5. `AGENTS.md` for repository workflow
6. archive records
