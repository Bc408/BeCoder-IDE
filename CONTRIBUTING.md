# Contributing to BeCoder

The BeCoder-specific contribution guide is not yet published. Creating it is tracked as project documentation work in [BECODER_CURRENT.md](BECODER_CURRENT.md).

Until that guide is complete, repository work must follow [AGENTS.md](AGENTS.md), the reading and authority order in [BECODER_HANDOFF.md](BECODER_HANDOFF.md), [BECODER_PHILOSOPHY.md](BECODER_PHILOSOPHY.md), [BECODER_CURRENT.md](BECODER_CURRENT.md), and the relevant current product contract. Historical Visual Studio Code contribution and issue-triage instructions do not define the BeCoder workflow.
