# OJ Connect

BeCoder 内置刷题扩展，当前源码接入洛谷与 AtCoder。需要包含对应浏览器宿主的 BeCoder 构建。

聚焦 C/C++ 源码，**Ctrl+Alt+P** 查看题面，**Ctrl+Alt+S** 提交当前编辑稿（含未保存内容），正式 ID 确认后打开共同评测页。题面可选择站点语言，快捷键沿用同一选择；尚未取得可用语言时在提交时选择。洛谷使用内置浏览器同一持久会话直接请求，常规操作无需保留网页；验证码按上游图片面板输入，留空刷新。AtCoder 按快捷键才建立本次官网提交页，正常验证后将源码直接放入完整表单请求发送一次，共用持久登录，不覆盖用户已有网页草稿；取得正式回执即释放任务页，结果查询独立进行；快捷键提交、受理核对和结果跟踪全程不自动显示网页。未登录时提示从侧栏主动登录后重新提交；原站验证在后台自动就绪时继续同一任务，若在期限内仍需人工验证则结束尚未发送的任务并提示主动到内置浏览器手动提交。保留用户自行打开的网页。

AtCoder 题面首次默认英文，主动选择的日／英偏好跨题、跨重启保留，缺失时仅对本题回退。洛谷与 AtCoder 分别按 C／C++ 保存本站编译器 ID，互不覆盖；同一站点的题面和快捷键使用同一选择。AtCoder 首次须明确选择，打开题面不会自动记下首项；洛谷无偏好时沿用首项，已有偏好失效则保持未选择，提交时要求重新选择。输入格式保留数学排版；样例输入／输出采用双栏，对应说明置于该组下方。

在内置浏览器题页点击 Import，将 `.cpp` 放在工作区直接子目录并打开共同题面；已有源码与未保存稿保留。题面上另点“导入 CPH”才把样例关联到这份源码。缺失限制会在 CPH 明示使用本地默认限制，不伪造网站数据。

`becoder.ojConnect.directories` 默认 `luogu`、`codeforces`、`atcoder`、`lanqiao`、`nowcoder`，设置修改不会移动已有文件。直接父目录优先，再猜文件名；失配提示输入，不建持久绑定库。例：`luogu/P1001.cpp`、`atcoder/abc086_a.cpp`；显式上下文例 `P1001@123.cpp`、`tenka1-2019-beginner@tenka1_2019_a.cpp`。无目录的 `AT_abc086_a.cpp` 有歧义时提示，不静默选站。

设置页搜索 `OJ Connect` 可调整以下设置。编译器与题面语言是跨项目的个人设置，页面选择写入对应设置，不另存隐藏偏好：

| 设置（前缀 `becoder.ojConnect.`） | 用途 |
| --- | --- |
| `luogu.cCompiler`、`luogu.cppCompiler` | 分别保存洛谷 C／C++ 的语言 ID，含本站支持的 `:o2` 后缀 |
| `atcoder.cCompiler`、`atcoder.cppCompiler` | 分别保存 AtCoder C／C++ 的数字语言 ID |
| `atcoder.statementLanguage` | 默认英文 `en`，可选日文 `ja`；本题缺失时仅临时回退 |
| `panelLocation` | 新题面／评测页的位置；默认 `auto` 复用源码右侧编辑组，否则并排；已有面板不移动 |

建议从题面或提交时的实际语言目录选择版本；清空编译器设置表示尚无偏好。旧版 AtCoder 本机偏好首次激活时迁入设置，不覆盖已有显式值，迁移成功才删除旧键。迁移写入失败会提示并保留未迁移项，扩展仍可使用。

独立 OJ Connect 活动栏入口提供五站登录摘要和已接入站点的登录／退出操作，与内置浏览器共用登录。CF、牛客、蓝桥显示“尚未接入”。没有题库、比赛、社交或专栏入口。

每窗口一项提交；洛谷明确验证码拒绝后人工输入可继续，同一次提交中已输入答案连续被拒绝三次即停止，并在右下角提示“请到内置浏览器中提交，并手动完成认证。”首次挑战、留空刷新和取消不计入次数，不实现新的认证形式。受理不明只查询，不能自动重交。发送后不提供取消提交；关闭记录只停止本地跟踪，线上评测继续。AtCoder 正常评测持续查询至终态，不因固定两分钟停止；查询失败保留最后状态并提供继续查询。状态保留原站标识并提供中文解释，CE 显示实际可读的编译诊断。AtCoder 返回评测进度总数时，沿用洛谷蓝色测试点卡片与白色转圈；尚无数量时只显示整体等待，不虚构点数。扩展重启不恢复任务或最近记录；两站的各自编译器偏好与 AtCoder 题面语言通过用户设置保留。

洛谷推送失败后停止本地跟踪，保留最后结果并提供“继续查询”；点击后重新读取同一正式记录，按需重建推送，不自动重连。隐藏或未知状态显示原始信息与说明，停止自动查询及转圈，允许手动继续查询；正常排队和评测状态仍自动更新。

题面与评测前端按 vscode-luogu 4.20.0 对齐，直接复用其核心 React 组件、CSS 与宿主 Markdown 渲染链，移除题解、比赛及其他外围能力；原组件及必要适配对照见 UPSTREAM.md。

开发命令：`npm run typecheck`、`npm run build`、`npm test`、`npm run test-render`。构建包含站点脚本、Webview JS/CSS、KaTeX 字体；运行时无外部 npm 依赖。许可与来源见 UPSTREAM.md、ThirdPartyNotices.txt。设计、当前检查和真实验收分别见 [开发入口](../../docs/oj-connect/README.md)。本次两站共同界面仍需负责人在新构建验收。
