## 链路、参数与验收边界

生产Store、Coordinator、ContextTools、History／Session、Provider及AI SDK参与链路；编辑器owner、网站题面响应、用户证据生产输入是合成边界。五站正常使用、登录／交题、安装版GUI及负责人体验未由本批合成模型测试证明。讨论对象仍由LLM判断。

源码指纹全部按read_bytes的SHA-256复核；旧manifest仍保持原时点身份，最终选择源码映射不将历史模型运行升级为后续源码验收。

工程修正包括工具返回的硬容量余量、近期目录最新优先及sequence、按实际提问取材的导师提示，以及压缩当前问题去重。评估器另修正实际工具交付正文和编辑分支的检查窗口。Beacon289项、原生57项、评估器54项、报告器13项及lint／type／layers的精确命令、退出码和失败历史见`.superpowers/sdd/2026-11-23-beacon-context-effect-evaluation/checks.jsonl`；这些工程回归不替代模型语义评分。
